# Frontend — Distribuição de roteadores

Interface React, TypeScript e Vite para configurar cenários, executar os métodos da API e comparar a cobertura dos roteadores.

## Executar

Com a API disponível em `http://127.0.0.1:8000`:

```bash
npm install
npm run dev
```

O proxy configurado em `vite.config.ts` encaminha as chamadas de `/api` para o backend.

## Verificar

```bash
npm run build
npm run lint
```

A documentação completa do sistema está em [`../DOCUMENTACAO.md`](../DOCUMENTACAO.md).
